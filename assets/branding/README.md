# VRAVEN signature assets

The VRAVEN signature is the upward-facing, open-beak raven with a red eye on a
red-and-black field. The full signature pairs that mark with the exact uppercase
wordmark `VRAVEN`.

## Usage

| Context | Asset |
|---|---|
| Source master for square signatures | `masters/vraven-signature-square-master.png` |
| GitHub organisation avatar | `avatars/vraven-avatar-500.jpg` |
| Package or application icon | `avatars/vraven-avatar-256.png` |
| Small interface icons | `avatars/vraven-avatar-128.png`, `vraven-avatar-64.png`, `vraven-avatar-32.png` |
| Square publication or catalogue thumbnail | `thumbnails/vraven-signature-square-1024.jpg`, `vraven-signature-square-512.jpg` |

## Signature rules

- Use the 500 px export for GitHub's organisation profile.
- Use the full `VRAVEN` signature for covers and large thumbnails.
- Keep the raven facing upward with its beak open; this pose is the identifying silhouette.
- Preserve the black, red and metallic-white palette and the red eye.
- Do not stretch, rotate, recolour or mirror the signature.
- Do not crop through the eye, beak or wordmark.
- Keep clear space around the beak, eye and all six letters of `VRAVEN`.
- Do not place additional text inside the signature artwork.

Working generations are kept locally under `drafts/` and are intentionally excluded
from version control. Promote only approved assets into the folders listed above.
