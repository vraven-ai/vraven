# VRAVEN Design References

These images were supplied by the project owner as visual quality references.

They illustrate:

* Compact scientific information density
* Dark navy interactive styling
* Fine borders and restrained panel separation
* Strong semantic colour contrast
* Clear model depth progression
* Coordinated representation views

They must not be copied as a single VRAVEN dashboard. Core VRAVEN outputs must be implemented as independent visualisations, each answering one scientific question.

The images are design references only. Their displayed data, labels, metrics and exact layouts must not be reproduced or treated as validated VRAVEN outputs.
