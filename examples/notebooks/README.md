# VRAVEN notebooks

These notebooks are complete research examples rather than required package files.

- `kronodroid_vraven_explain.ipynb`: single-model Kronodroid explanation audit.
- `winlolbin_vraven_explain.ipynb`: Windows LOLBin explanation workflow.
- `winlolbin_vraven_darkside.ipynb`: Windows LOLBin internal-mechanism audit.

Run notebooks from the repository root so their relative dataset, model and output paths resolve consistently.
