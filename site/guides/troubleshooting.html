Guide 08 · Troubleshooting

Fix the common failure first.

“Requires-Python >=3.10”

Your pip belongs to an older interpreter. Create the environment with an explicit modern Python and always install through that environment's Python:

python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install vraven

“No module named …” for the model factory

Run from the project that contains the module, install your project into the environment, or place architecture.py inside a VRAVEN model bundle and use architecture:Classifier.

A model.pt file will not load

Determine how it was saved. A state dictionary needs the original architecture factory. A full pickled module needs --model-format pickle --trusted-model and must come from a trusted source.

PDF export is unavailable

Run vraven doctor. Use HTML immediately, or install a browser supported by the local PDF exporter.

The requested analysis is unsupported

Read the emitted limitation or coverage field. VRAVEN preserves unsupported operators and missing evidence instead of inventing an answer. Try a less demanding mode only if it still answers your question.

Still blocked?Capture vraven doctor, the exact command and the complete error, then open an issue without attaching private models or data.
