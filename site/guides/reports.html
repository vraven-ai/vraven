Guide 06 · Output

Create one report for one audience.

VRAVEN deliberately writes one selected report per invocation. That keeps commands predictable and prevents stale output from being mistaken for current evidence.

FormatBest for
htmlInteractive local review and sharing as one self-contained page.
pdfArchival review and fixed-layout submission. Browser-based PDF support must be available.
jsonAutomation, reproducibility checks and downstream analysis.

HTML

vraven demo --mode gradient \
  --report-format html \
  --output explanation.html

PDF

vraven demo --mode gradient \
  --report-format pdf \
  --output explanation.pdf

JSON

vraven demo --mode gradient \
  --report-format json \
  --output explanation.json
Check before PDF exportRun vraven doctor. Its pdf_report_available field tells you whether a supported browser is available for PDF rendering.
