Guide 07 · Command map

Choose the smallest command for the question.

Begin with analyse. Move to a focused command when you need explicit scientific controls.

QuestionCommandResult
Is my environment ready?vraven doctorCapability report
What does VRAVEN support?vraven featuresFeature inventory

Is this model folder valid?vraven bundleValidated bundle summary
How do I capture one real execution?vraven captureTrace and Mechanism IR
Why did this prediction occur?vraven explainHTML, PDF or JSON report
Can the decision be decompiled?vraven reverseDecision Proof and signature views
How does it behave under attack?vraven adversarialEmpirical stress report
What bounded change flips it?vraven counterfactualCounterfactual evidence
Is the score stable to noise?vraven stabilityStability measurements
How does relevance propagate?vraven lrpEpsilon-rule LRP result
Can local robustness be proved?vraven certifyFormal result for supported operators
What patterns occur across samples?vraven datasetReasoning-fingerprint atlas
How do two models differ?vraven compareMatched-model comparison
How did checkpoints change?vraven evolutionCheckpoint evolution report
Which Linear units matter locally?vraven anatomyMeasured local anatomy
Can I run a deterministic example?vraven demoLocal demonstration report
Can I exercise the decompiler?vraven decompile-demoDecompilation demonstration

Can I render one saved figure?vraven renderStandalone visual export
Can I generate the full observatory?vraven ravenGrouped Capture, Reverse, Proof, Atlas, Watch, Compare and DarkSide output
