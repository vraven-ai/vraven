Run this with the installed CLI

Point VRAVEN at a validated model bundle. This produces one focused HTML report and works after a normal PyPI installation.

vraven analyse ./my-model \
  --task explain \
  --preset standard \
  --format html \
  --output vraven-report.html

Start with the model-folder guide if your bundle is not prepared yet. The larger documentation fixture is a contributor workflow described in Develop from source.

Generate this view

from vraven.darkside import analyse_causal_synergy

result = analyse_causal_synergy(model, inputs, target=target, groups=unit_groups)
figure = result.figure(mode="publication_light")
figure.write_html("result.html")

How to read the result

  1. Start with the title and target metadata in the generated report.
  2. Read the strongest structures first, then inspect weaker or opposing evidence.
  3. Check the stated evidence level and status before treating a relationship as causal or formal.
  4. Retain the trace, model version, preprocessing, and VRAVEN version with any published claim.
