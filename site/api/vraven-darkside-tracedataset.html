TraceDataset

TraceDataset(sample_ids: 'tuple[str, ...]', true_labels: 'np.ndarray', predicted_labels: 'np.ndarray', target_scores: 'np.ndarray', representations: 'dict[str, np.ndarray]', unit_influences: 'dict[str, np.ndarray]' = <factory>, unit_energies: 'dict[str, np.ndarray]' = <factory>, activation_rms: 'dict[str, np.ndarray]' = <factory>, timing_ms: 'dict[str, np.ndarray]' = <factory>, fingerprints: 'np.ndarray | None' = None, metadata: 'dict[str, Any]' = <factory>) -> None

Aligned sample-level internal measurements.

Rows in every matrix refer to the same ``sample_ids`` in the same order.
This alignment is mandatory for CKA, neighbourhood and paired stability
analyses.
