detect_shortcut_reliance

detect_shortcut_reliance(model: 'torch.nn.Module', inputs: 'Any', *, target: 'int | None', feature_groups: 'Sequence[InputFeatureGroup]', baseline: 'str' = 'zero', config: 'VRavenConfig | None' = None) -> 'AnalysisResult'

Measure whether narrow input groups dominate a local prediction.

The output is a *shortcut suspicion* audit. A large score drop after changing
a semantically brittle group shows local dependence, but proving a shortcut
also requires domain evidence that the group is non-causal or unstable.

Usage

from vraven.darkside import detect_shortcut_reliance

result = detect_shortcut_reliance(... )
