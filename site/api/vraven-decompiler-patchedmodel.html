PatchedModel

PatchedModel(model: 'nn.Module', concept_interventions: 'Mapping[str, float | Callable[[torch.Tensor], torch.Tensor]]') -> 'None'

Wrapper around a PyTorch model that enforces causal concept interventions at runtime.

Usage

from vraven.decompiler import PatchedModel

value = PatchedModel(...)
