map_class_conditional_unit_field

map_class_conditional_unit_field(dataset: 'TraceDataset', *, class_a: 'Any', class_b: 'Any', label_source: 'str' = 'true', max_units_per_layer: 'int | None' = 128) -> 'AnalysisResult'

Dense unit-field map of class contrast for every shared influence layer.

Unlike ``compare_class_conditionals``, this keeps a full (or capped) unit
grid so the figure can show a scientific layer×unit field rather than a
top-k bar summary.

Usage

from vraven.darkside import map_class_conditional_unit_field

result = map_class_conditional_unit_field(... )
